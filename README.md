## 📌 Sobre o Projeto

Este projeto foi desenvolvido como uma iniciativa de **Extensão Divertida**, combinando aprendizado prático de desenvolvimento com o humor de memes da internet. O objetivo principal foi criar uma aplicação interativa, leve e divertida baseada no famoso **Meme do Almir**.

Além do entretenimento, o projeto permitiu colocar em prática conhecimentos teóricos de programação, design de interface e trabalho em equipe, conectando a comunidade acadêmica através do humor.

---

## 🚀 Funcionalidades

- 🎭 **Galeria do Almir:** Exibição dos melhores memes e imagens do Almir.
- 🎨 **Interface Temática:** Design descontraído focado no meme.

## 💻 Como Executar o Projeto

### Pré-requisitos
- Um navegador web atualizado (Google Chrome, Firefox, Edge, etc.).

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/projeto-almir.git
   ```

2. **Navegue até a pasta do projeto:**
   ```bash
   cd projeto-almir
   ```

3. **Execute a aplicação:**
   - Abra o arquivo `index.html` diretamente no seu navegador.
   - *Ou, se estiver usando um servidor local (como Live Server no VS Code), basta iniciar o servidor.*
